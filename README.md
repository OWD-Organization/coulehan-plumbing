# Coulehan Plumbing LLC

Preview marketing site for Coulehan Plumbing LLC, an owner-operated plumbing company in Pittsburgh, PA 15226. Built for review by Orion Ra at OUTWORK'em DIGITAL.

This build is **not for indexing**. Every page sends `noindex, nofollow`, `public/robots.txt` disallows `/`, and `vercel.json` sets `X-Robots-Tag: noindex, nofollow`. There is no sitemap.

## Run locally

```bash
npm install
npm run dev
```

The dev server is http://127.0.0.1:3847

```bash
npm run build
npm run preview
npm run check:seo
```

Deploy the static `dist/` folder on Vercel. `vercel.json` is already in the repo. No environment variables are required.

## Photos

Job photos and the logo come from the business Facebook archive. They are real job photos. Nothing here is stock or generated.

Optimized files live in `public/media/` (AVIF, WebP, and JPG at 720 and 1600 pixels wide, or narrower when the source was smaller). Phone GPS and other EXIF were stripped. Processing is limited to rotate, resize, a light sharpen, and a small brightness lift only if a frame was very dark (the optimizer logs those files).

The original tarball is not in git. To rebuild derivatives:

```bash
ASSET_SRC=/path/to/coulehan npm run optimize
```

`src/data/manifest.json` is generated by that script. Do not edit it by hand.

Brand color, eyedropped from `logo.jpg`:

- Navy ground, pixel (0,0): `#182033`
- Water-drop face: `#4199E1`

## What this preview does not do

- It does not send quote requests.
- It does not embed Facebook video. Video-only posts link out.
- It does not invent a street address, license number, founding year, or hours.
- It does not include a sitemap, and it must stay `noindex` until the TODOs above are resolved and someone deliberately removes the robots rules.
